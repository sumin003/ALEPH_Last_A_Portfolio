# 우수민 포트폴리오

HTML·CSS·JavaScript로 구성한 공개 소개 사이트입니다. GitHub main 브랜치와 연결된 Vercel에서 배포합니다.

## 사이트에서 기록 반영하기

1. 페이지 아래의 **내 기록을 사이트에 반영하기**에서 리추얼 또는 기록 JSON 파일을 선택합니다. 파일을 읽으면 숫자 칸과 문단 후보가 바로 바뀝니다.
2. 후보의 날짜와 근거, 개인 이름·연락처 포함 여부를 확인하고 원하는 문장을 선택한 뒤 **선택한 문장 반영**을 누릅니다. 승인한 문장만 이야기에 추가됩니다.
3. 반영 결과는 현재 브라우저에 저장됩니다. 다른 방문자에게도 공개하려면 **다른 방문자에게도 변경 내용 공개하기**에서 반영 파일을 받고, 압축을 풀어 GitHub 파일을 교체합니다.

기록 파일은 서버로 전송하지 않습니다. 브라우저 저장이 제한된 경우에는 현재 화면에만 반영된다는 안내를 표시합니다. ‘원래 화면으로’는 이 브라우저의 반영 결과를 지우고 배포된 기본 화면으로 돌아갑니다. 개인 파일을 선택하는 것만으로 공개 서버의 데이터를 변경하지는 않습니다.

## 입력 형식

- 리추얼 내보내기: `{"days":[{"date":"YYYY-MM-DD","open":["..."],"close":["..."]}]}`. 시작·마무리 배열이나 기록 유무 불리언을 지원합니다.
- 일반 기록: `{"records":[{"date":"YYYY-MM-DD","ability":"자기동기력","text":"본인이 쓴 기록"}]}`. 능력 이름은 자기조절력·대인관계력·자기동기력 중 하나입니다.
- 과제 목록: `{"items":[{"id":"T01","status":"completed"}]}`. 과제 ID 범위는 T01~T11입니다. 기본 목록은 11개이며 완료·제출률로 표시하지 않습니다.
- 출석 파일: `{"as_of":"YYYY-MM-DD","attended_days":0,"scheduled_days":0}`. 실제 출석 자료가 있을 때에만 넣습니다.

내용이 있는 기록 날짜를 중복 없이 셉니다. 주 수는 월요일~일요일 달력주입니다. 문단 후보는 본인의 경험·회고 필드에서 능력과 관련된 낱말을 찾아 만들며, 능력 검사 점수나 사실 검증의 대체 수단이 아닙니다. 같은 파일과 같은 과제·출석 입력이면 같은 숫자와 후보가 나옵니다. 원문에 없는 사건을 생성하거나 승인하지 않은 후보를 공개 본문에 넣지 않습니다.

## 파일

- `index.html`: 다섯 묶음으로 정리한 이야기, 숫자, 대표작, 지원 문서, 기록 입력 도구
- `style.css`: 화면과 모바일 레이아웃
- `script.js`: 파일 읽기, 숫자 반영, 문단 승인, 브라우저 저장과 공개 반영 파일 생성
- `record-engine.js`: 날짜 검증, 중복 제거 집계, 능력별 후보 생성
- `data/site-data.json`: 배포된 기본 집계와 공개 문단
- `data/tasks.json`: T01~T11 과제 목록
- `documents/`: 지원 문서와 공개 논문 사본

이야기의 날짜 표시와 제출용 ZIP 다운로드 링크는 요청에 따라 제외했습니다. 숫자의 근거 기간과 기록 후보의 근거 날짜는 확인할 수 있도록 유지합니다.
